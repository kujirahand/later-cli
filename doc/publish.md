# PyPIへのパッケージ公開手順 (publish)

本ドキュメントでは、`later-cli` を Python Package Index (PyPI) に登録し、`pip install later-cli` で世界中からインストールできるようにするための公開手順を解説します。

---

## 1. パッケージのビルド

`later-cli` は、パッケージングと依存関係の管理に `uv` および `hatchling` ビルドシステムを採用しています。
配布用のパッケージ（ホイールとソース配布物）を作成するには、プロジェクトのルートディレクトリで以下のコマンドを実行します。

```bash
uv build
```

実行が成功すると、プロジェクトのルートに `dist/` ディレクトリが作成され、以下のファイルが生成されます。
* `dist/later_cli-X.Y.Z-py3-none-any.whl` (Wheelファイル)
* `dist/later_cli-X.Y.Z.tar.gz` (ソース配布物)

---

## 2. PyPIへのアップロード (公開)

`uv` にはパッケージの公開を行うための `uv publish` コマンドが標準で用意されています。

### 2.1. 標準的なアップロード方法
ビルド完了後、以下のコマンドを実行します。

```bash
uv publish
```

コマンドの実行中に認証情報を求められますので、以下のように入力します。

* **Username**: `__token__` （※ 完全にこの通りの文字列を入力してください）
* **Password**: [ステップ 1.2](#12-pypiアカウントの作成とapiトークンの取得) で取得した `pypi-...` から始まる API トークンを入力または貼り付けます。

これでパッケージが PyPI にアップロードされ、即座に公開されます。

### 2.2. 環境変数を使用したアップロード方法
認証情報の入力を省略し、より安全かつスムーズにアップロードを行うには、環境変数 `UV_PUBLISH_PASSWORD` に API トークンを設定して実行します。

```bash
# 環境変数にトークンを設定
export UV_PUBLISH_PASSWORD="pypi-YourActualTokenHere"

# アップロードを実行
uv publish
```

---

## 3. 公開後の確認

アップロードが正常に完了したら、正しく公開されているかテストしてみましょう。

1. [PyPI](https://pypi.org/) で `later-cli` を検索し、プロジェクトページが作成されていることを確認します。
2. 任意のクリーンな環境で、実際にインストールを実行してみます。
   ```bash
   pip install later-cli
   ```
3. インストール完了後、以下のコマンドで動作を確認します。
   ```bash
   later version
   ```
   *※ 正常にインストールされていれば、`later-cli vX.Y.Z` が表示されます。*
