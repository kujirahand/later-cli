# later-cli クイックスタートガイド

`later-cli` は、ターミナルで簡単にタスクを管理できるシンプルなCLIツールです。このガイドでは、基本的な使い方について説明します。

インストール方法については、[こちら](https://github.com/kujirahand/later-cli/)を参照してください。

## 0. 表示言語の設定

デフォルトでは、表示言語は英語に設定されています。表示言語を日本語に変更したい場合は、以下のコマンドを実行します：

```sh
later language ja
```

英語に戻す場合は、以下のコマンドを実行します：

```sh
later language en
```

## 1. タスクの追加

タスクを追加するには、`add` コマンド（またはエイリアス `a`）を使用します。

```sh
# 簡単なオフセット形式
later a 3d "レポート提出"       # 3日後の午前8時にタスクを追加
later a 10h "会議"            # 10時間後にタスクを追加

# 自然言語形式
later a "今日" "今日の予定"               # 今日の午前8時にタスクを追加
later a "明日" "明日の予定"               # 明日の午前8時にタスクを追加
later a "明日 20:00" "明日の夜 of 予定"   # 明日の午後8時にタスクを追加
later a "明後日" "明後日の予定"           # 明後日の午前8時にタスクを追加
later a "来週" "来週の予定"               # 来週月曜日の午前8時にタスクを追加
later a "来週月曜" "レポート提出"         # 来週月曜日の午前8時にタスクを追加
later a "水曜日" "ゴミ出し"               # 次の水曜日の午前8時にタスクを追加
later a "来月第二月曜" "月次報告"         # 来月の第2月曜日の午前8時にタスクを追加
later a "明日 10:00" "レポート提出"       # 明日の午前10時にタスクを追加

# 具体的な日時指定形式
later a "5/25" "タスク内容"             # 5月25日の午前8時
later a "12/3 15:30" "タスク内容"       # 12月3日の午後3時30分
```

## 2. タスクの確認

タスクをテーブル形式で一覧表示するには、`list` コマンド（またはエイリアス `ls` や `show`）を使用します。

```sh
later list
```

## 3. タスクの削除

タスクを削除するには、`delete` コマンド（またはエイリアス `del`）の後に、一覧に表示されているタスク番号を指定します。

```sh
later delete 1  # 一覧の1番目のタスクを削除
```

## 4. 期限超過タスクの一括削除

期限が切れたタスクをすべて一括で削除するには、`clear` コマンドを使用します。

```sh
later clear
```

## 5. 期限超過タスクのチェック

期限が過ぎているタスクのみを表示するには、`check` コマンドを使用します。

```sh
later check
```

## 6. カレンダー表示による週間スケジュールの確認

カレンダー形式で週間のスケジュールを確認するには、`cal` コマンドを使用します。

```sh
later cal
```

![週間カレンダー](later-cal.png)

カレンダーに表示する日数をカスタマイズしたい場合は、`--d` オプションを使用します：

```sh
# 今後30日間のスケジュールをカレンダー形式で表示
later cal --d 30
```

また、ショートハンドコマンド `later cal30` を使用して、30日間のカレンダービューを素早く表示することもできます。

## 7. データファイルの保存場所の確認

タスクのJSONデータが保存されている絶対ファイルパスを確認するには、`info` コマンドを使用します。

```sh
later info
```

## 8. タスク状態の変更

タスクを「完了（done）」にするには、`done` コマンドの後にタスク番号を指定します：

```sh
later done 1  # 1番目のタスクを完了にする
```

完了したタスクを一括で削除するには、`clear --target=done` コマンドを使用します：

```sh
later clear --target=done  # すべての完了済みタスクを削除
```

完了したタスクを「未完了（todo）」に戻すには、`todo` コマンドの後にタスク番号を指定します：

```sh
later todo 1  # 1番目のタスクを未完了に戻す
```

## 9. API同期機能 (sync)

複数のデバイス間でタスクを同期したり、リモートサーバーにバックアップしたりできます。同期を実行すると、ローカルのイベントログ（タスクの作成、削除、ステータスの変更など）がAPIに送信（プッシュ）され、同時にサーバー上の最新イベントを受信（プル）してローカルタスクが更新されます。

### 同期の設定

同期を設定するには、`set` コマンドを使用して、APIエンドポイントのURLとAPIキーを `tasks.json` のメタデータに設定します：

```sh
# リモートAPIエンドポイントのURLを設定
later set api_endpoint "https://example.com"

# APIキーを設定 (形式: laterapi::xxx::xxxx)
later set api_key "laterapi::your_api_key_here"
```

### 接続および認証テスト (sync hello)

リモートエンドポイントとAPIキーが正しく設定されているかを確認するには、`sync hello` コマンドを実行します：

```sh
later sync hello
```

疎通に成功すると、接続成功メッセージとサーバーからの応答メッセージが表示されます。接続エラーや認証失敗が発生した場合は、エラーの詳細な原因が表示されます。

### 同期の実行 (sync)

実際に双方向の同期を実行するには、`sync` コマンドを実行します：

```sh
later sync
```

これにより、未同期のローカルイベントがリモートサーバーに送信され、前回の同期以降のリモート側の変更が取得されてローカルのタスクファイルに適用され、最後に同期成功のタイムスタンプが記録されます。
